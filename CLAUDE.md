# Bretford dashboard (`/bretford/library`)

Sub-app hasil slicing Figma "TWITTER", hidup di route `src/app/bretford/library/` dengan kode di `src/bretford/` dan aset di `public/bretford/`. Token, primitives, dan konvensinya sengaja dipisah dari site utama:

- Token Bretford ada di bagian "Bretford" `src/app/globals.css` (`text-loud`, `text-normal`, `bg-base`, `shadow-card`, `rounded-card`, dst.) — jangan dipakai di halaman mal.gg, dan token site (`ink`, `page`, `card`, …) jangan dipakai di Bretford. Font: `font-bretford` (Geist, di-load di `src/app/bretford/library/layout.tsx`); site tetap Inter.
- Primitives: `src/bretford/components/ui/` — `Button` (md 32px / lg 44px), `Chip`/`StatusBadge`/`Tag`, `Avatar`, `Field`, `Select` (APG select-only combobox, menu di-portal), `Toast`, `Icon` (SVG di `public/bretford/icons`, via `asset()` di `src/bretford/lib/asset.ts`). Reuse, jangan duplikasi.
- Konten data-driven: `src/bretford/lib/library-data.ts` dan `sources-data.ts` (tambah slug di `sourceSlugs` + entry = halaman baru). Link internal lewat `src/bretford/lib/routes.ts`.
- Motion: `src/bretford/components/motion/page-motion.tsx` membungkus tiap page; target entrance = atribut `data-motion` (disembunyikan sampai dianimasikan), `data-count` count-up, `data-lift`/`data-nudge` hover. anime.js v4 named imports.
- Pembatas section pakai utility `rule-b`/`rule-r` (hairline inset) — stroke Figma ada di dalam, jadi tinggi bar tetap presisi. Dialog: native `<dialog>` + `showModal()` dengan overlay blur di dalamnya (`invite-modal.tsx`); dengarkan event `close` native juga.
- Gotcha stacking: `drop-shadow` (CSS filter) dan sisa inline `transform` dari anime.js bikin stacking context — apa pun yang harus mengambang di atas sibling (menu, popover) di-portal, dan grup yang dianimasikan membersihkan inline style-nya setelah selesai.
- Verifikasi: `npx tsc --noEmit`, `npx eslint .`, `npm run build`. Referensi visual: Figma node 866:6922 (Library), 866:7241 (detail), 866:7958 (modal), 866:7953 (toast), Rolexis 782:22837 (dropdown).
- Mobile (Rolexis "Responsive" frames, 375 lebar): breakpoint `md` (768px). Desktop ≥ md harus tetap pixel-identik — perilaku mobile hanya lewat varian `max-md:` / `md:`. Di bawah md: sidebar diganti `MobileTopBar` (logo + hamburger `aria-label="Open menu"` + avatar 36px) dan drawer `MobileMenu` (native `<dialog>`, slide dari kanan, tutup via Escape / tap overlay / `flex-align-left`, fokus balik ke hamburger); panel putih `m-2 rounded-[16px]` tumbuh mengikuti konten dan halaman yang scroll. `Button` md membesar ke 36px sentuh (`touch={false}` untuk yang tetap 32px, mis. Invite full-width); ghost "expand" tetap 32px. Tabel lebar (Member/Candidate/Database) scroll ke samping: detail memakai `TableScroller` (`components/ui/table-scroller.tsx`, track 4px + thumb 24px seperti frame), Database pakai `overflow-x-auto` biasa. Modal Invite jadi sheet 335px dengan Send Invite di atas Cancel, toast `inset-x-4 bottom-4`. Screenshot mobile: headless Chrome via CDP dengan `Emulation.setDeviceMetricsOverride` `{width:375, mobile:true}` + `Page.captureScreenshot` `captureBeyondViewport` (contoh skrip: scratchpad `cdp-mobile.mjs <url> <out.png> [--menu|--modal] [--height N]`); pastikan `document.documentElement.scrollWidth <= 375`.

# YC Founder Directory (`/yc`)

Sub-app kedua, di-slice dari Figma "Y-Combinator Data Library". Route di `src/app/yc/` (page + `api/suggest`, `api/count`), kode di `src/yc/` (`components/`, `lib/`), ikon di `public/yc/figma/`, data di `data/yc.db`.

- **Data**: SQLite read-only (`data/yc.db`, ~26 MB, rollback-journal — bukan WAL) dibaca lewat `better-sqlite3` (native addon → `serverExternalPackages`; file DB di-trace ke function via `outputFileTracingIncludes`). File ini **hasil pack** dari pipeline di repo `TWITTER/YC` (`npx tsx scripts/pack-web-db.ts "<path repo ini>/data/yc.db"`) — jangan diedit tangan; regenerate di sana kalau datanya berubah.
- **Token**: semua di bagian "YC" `src/app/globals.css` dengan prefix `yc-` (`text-yc-ink`, `bg-yc-subtle`, `border-yc-line`, `shadow-yc-card`, `.yc-card`/`.yc-panel`/`.yc-popover`, `font-yc-sans`/`font-yc-mono` = Geist). Base style (font 12px, line-height 1, bg) di-scope ke `.yc-root` di `src/app/yc/layout.tsx` — jangan pakai token `yc-` di luar `/yc`, dan jangan pakai token site/Bretford di dalamnya.
- **URL = state**: semua filter/sort/view/panel ada di query string (`src/yc/lib/query.ts`, grammar di komentar atasnya). Prefix path lewat konstanta `BASE = "/yc"` — semua `Link`, `fetch`, dan `<img>` aset wajib lewat situ.
- **Facet registry** `src/yc/lib/facets.ts`: satu entry = satu filter (sidebar, chip bar, popover, count, zero-state ikut otomatis). Engine query + facet count (temp table di memori) di `src/yc/lib/search.ts`.
- **Motion**: panel detail (`PanelChrome.tsx`) pakai anime.js v4 `createScope` (slide-in, cascade section `.peek-section`, exit sebelum URL berubah, `prefers-reduced-motion` di-hormati, exit di-race 400 ms).
- Verifikasi: `npx tsc --noEmit`, `npx eslint src/yc src/app/yc`, `npm run build` (jangan barengan `next dev`). Smoke: `/yc`, `/yc?f=status:is:Active&peek=<id>`, `/yc/api/count?f=…`.

# Brainrot Surfers (`/brainrotsurfers`)

Sub-app keempat: Subway Surfers KW gratis dengan karakter Italian brainrot (three.js + overlay React, UI bahasa Inggris). Route di `src/app/brainrotsurfers/` (layout = metadata + `viewport` + Lilita One; page = `GameMount`), kode di `src/brainrotsurfers/` (`game/` engine tanpa React, `components/` overlay, `lib/` registry/save/store), aset di `public/brainrotsurfers/` (`models/`, `models/env/`, `audio/`).

- **Aturan produk**: shop cuma jual karakter (9 karakter, Tung Tung Tung Sahur gratis & default), mata uang = koin hasil lari, pengejarnya kucing OIIA yang selalu muter. Gak ada iklan / pembelian uang asli.
- **Engine**: `game/engine.ts` (`Game`: state machine loading → menu ⇄ shop/credits → running ⇄ paused → caught → over) dipegang `components/game-canvas.tsx`; React cuma panggil API publiknya (`start`, `pause`, `openShop`, `previewCharacter`, `buyCharacter`, …) dan baca `lib/store.ts` (`GameSnapshot`). Fisika pemain = data murni di `game/motor.ts` + `game/collision.ts` (AABB, dunia lengkung cuma visual di `game/curve.ts`). Semua angka gameplay di `game/config.ts`.
- **Rintangan**: chunk buatan tangan di `game/chunks.ts`, dipilih `game/spawner.ts` (tier, mirror, swap jump↔roll). Tiap chunk wajib lolos `npx -y tsx src/brainrotsurfers/game/spawner.check.ts` (BFS pakai fisika asli, semua lane masuk, 15–33 m/s). Run panjang tanpa browser: `npx -y tsx src/brainrotsurfers/game/autopilot.sim.ts 120 60 42`.
- **Visual = seam**: mesh dibuat lewat factory di `game/entities/visuals.ts` dan `game/world/*`; logika gameplay cuma bergantung ke dimensinya (kereta 2.1 × 3.4 m, dst.). Lingkungan = satu `models/env/env.glb` + `env-atlas.png` (satu material per objek → draw call rendah, ±60–75 saat main).
- **Karakter**: registry `lib/characters.ts` (harga, normalisasi `rotationY`/`height`/`maxWidth`/`pose`/`tint`, klip, gerak prosedural per karakter, kredit). GLB gagal dimuat → placeholder prosedural, gak pernah crash. Kredit lingkungan/audio/font di `lib/credits.ts`; layar Credits wajib ada (lisensi CC BY; Cappuccino Assassino CC BY-NC — aman karena gamenya gratis).
- **Aset mentah** di `SUBWAY SURVERS KW/` (gitignored: GLB Sketchfab, zip Kenney/Poly Pizza, audio Kenney/OGA). Diubah ke versi web oleh `node scripts/brainrotsurfers-assets.mjs [id…]` (karakter, gltf-transform meshopt + WebP 512), `node scripts/brainrotsurfers-env-assets.mjs` (env.glb + atlas, butuh `sharp`) dan `node scripts/brainrotsurfers-audio-assets.mjs` (mp3 via ffmpeg; loop musik sample-accurate, panjangnya di `TRACKS` `game/audio.ts`).
- **Audio**: `game/audio.ts` (WebAudio; dibuka di gesture pertama; fallback synth kalau file gagal). Suara "OIIA" kucing disintesis formant, jangan pakai sampel meme.
- **Token**: bagian "Brainrot Surfers" di `src/app/globals.css`, prefix `br-` (`text-br-ink`, `bg-br-sky`, `font-br-display`, …), base + kunci layar penuh (no scroll/zoom/overscroll) di-scope ke `.br-root`. Jangan pakai token site/Bretford/YC/fp — termasuk `text-base`, yang di repo ini nyambung ke warna Bretford (pakai `text-[1rem]`).
- **Debug (dev saja)**: `window.__brDebug` (`state()`, `autopilot(true)`, `setInvincible`, `setSpeed`, `powerUp(kind)`, `unlockAll()`, `character(id)`), `?seed=123` buat run deterministik. Gak ikut ke build production.
- Verifikasi: `npx tsc --noEmit`, `npx eslint src/brainrotsurfers src/app/brainrotsurfers scripts/brainrotsurfers-*.mjs`, `spawner.check.ts`, `npm run build` (jangan barengan `next dev`). Smoke di browser: `/brainrotsurfers` → tap/Space → panah/swipe; cek juga shop (beli & pilih), Credits, dan layar 375 × 667 + landscape 667 × 375.
